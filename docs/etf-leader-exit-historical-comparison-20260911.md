# ETF 龙头退出规则：真实历史比较（2026-09-11）

历史数据已接入实际的 ETF 突破 V2 筛选、生命周期确认和现金份额账户，并完成比较。三种退出政策本轮没有表现差异：只有两笔完整交易，都先触发 MA5 退出，未达到 1R 或 2R。不能据此认定固定止盈有效，也不能认定三种政策长期等效。

## 样本为什么仍然少

这次已完成全清单核对，不能再把“历史入口没接通”当作没有结果的原因。但数据覆盖和策略成交样本是两个不同阶段：

- 冻结清单：1,611 只，全部具有输入或明确排除记录。
- 进入研究输入：874 只，其中 735 只至少有 120 根日线，涉及 320 个不同跟踪标的；是否在某个信号日具备完整预热仍逐日检查。
- 原算法实际筛出：7 个突破候选，2 个完成买入确认，2 笔完整交易。
- 排除 737 只：指数事实缺失 596、主题事实缺失 87、主题分组不支持 40、指数明确未解析 7、上市事实缺失 4、行情不合格 2、比较区间后上市 1。原因按加载顺序互斥计数。

当前样本还受严格突破门槛、同指数去重、同类数量要求及确认条件限制。筛选中的多个失败理由可能同时作用于同一个 ETF/日期，不能把理由计数相加当成独立资产数。没有为了增加交易而放宽规则、删除失败资产或搜索参数。

Luna 对七个候选日重新调用原筛选和生命周期函数，候选 feature hash 及状态变更 hash 均一致。其余五个候选都在确认买入之前跌破 MA5 失效，因此没有买入或卖出成交：

这五个均不是因缺少未来价格而从成交统计中消失，也不是仍在等待确认的样本。09-10 的候选已经失效，区间内没有后续执行日；由于从未买入，不计为一笔待卖出的持仓。

## 证据边界与迭代判断

这是使用当前主题、指数身份和资产池重建的历史研究，保留真实接收时间，**正式 PIT 证据权重为 0**。737 只排除资产会影响可比池及代表性，不能把结果扩展为全市场结论。

本轮验证了“历史行情 → 龙头筛选 → 确认 → 成交 → 退出 → 扣费账户”已经衔接。只有两笔交易，且没有一次进入盈利保护或固定止盈分支，当前没有证据支持把固定 2R 升为默认。后续应继续原采集游标、积累已登记的前瞻样本，并观察盈利保护实际触发后的表现；不能依据这两笔亏损反向调参。
